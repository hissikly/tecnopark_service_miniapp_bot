# Технопарк MVP: Сервисная экосистема 🔥

## О проекте
Данный MVP представляет собой прототип сервисного модуля(в формате единого приложения/Telegram Mini App) для интеграции в экосистему компании **Технопарк**. 

**Главная цель проекта** — продемонстрировать сквозной путь пользователя (User Journey) при взаимодействии с сервисными тарифами компании:
* **Гарантия+** — базовый сервисный тариф, прикрепляемый к устройству при новой покупке. Дает приоритетное сервисное обслуживание и выделенное количество видеоконсультаций.
* **Постгарантия+** — расширенный премиальный мультидевайсный пакет. Покрывает сразу несколько устройств (в том числе старше 1 года), включает безлимитные консультации, скидки на ремонт и бесплатное техническое обслуживание (ТО).

В MVP реализованы все ключевые этапы:
1. Выбор тарифа в карточке товара при новой покупке.
2. Логика оформления заказа (Корзина -> Чекаут -> Успешная оплата).
3. Профиль пользователя с динамическим отображением активного сервисного статуса.
4. Раздел управления подпиской (Детали, Апгрейд тарифа, Список добавленной техники).
5. Маршрутизация обращений (в зависимости от категории проблемы и тарифа пользователю предлагается чат, видеоконсультация или вызов мастера/звонок).
6. Единая история обращений с динамическими статусами на основе глобального состояния.

## Стек технологий 🛠

* **Фреймворк:** React 18 + Vite
* **Маршрутизация:** React Router v7
* **Стилизация:** Tailwind CSS
* **Иконки:** Lucide React
* **Управление состоянием (State Management):** React Context API + \`useReducer\` (глобальное состояние, не требующее сторонних библиотек вроде Redux)
* **Интеграция с Telegram:** \`node-telegram-bot-api\` (для запуска в качестве Telegram Mini App)

## Руководство по запуску 🚀

### 1. Локальный запуск (В браузере)
Склонируйте репозиторий и установите зависимости:
\`\`\`bash
npm install
\`\`\`

Запустите сервер для разработки:
\`\`\`bash
npm run dev
\`\`\`
Приложение будет доступно по адресу (порт может отличаться): \`http://localhost:5174\`

### 2. Запуск в Telegram Mini App (через бота)
Для тестирования продукта непосредственно в интерфейсе Telegram необходимо пробросить туннель:

1. Запустите само приложение в фоне (\`npm run dev\`), запомните порт (напр. \`5174\`).
2. Запустите туннель \`ngrok\` или \`localhost.run\` на этот же порт:
   \`\`\`bash
   ngrok http 5174
   \`\`\`
3. Скопируйте полученную https-ссылку и сохраните её в файл \`.env\` в корне проекта:
   \`\`\`env
   WEBAPP_URL=https://ваша-ссылка.ngrok-free.app
   \`\`\`
4. Запустите скрипт бота:
   \`\`\`bash
   node bot.mjs
   \`\`\`
5. Откройте в Telegram вашего бота, введите \`/start\`, и MVP откроется как встроенное Mini App.

## Структура проекта 📂
- \`/src/components\` — Переиспользуемые UI компоненты.
- \`/src/layouts\` — Layout-обертки (содержат глобальную нижнюю навигацию, убирающуюся на иммерсивных экранах).
- \`/src/pages\` — Экраны продукта (Каталог, Товар, Корзина, Профиль, Чат и тд).
- \`/src/store.jsx\` — Централизованное хранилище приложения (моки данных, тарифы, активная подписка, устройства).
